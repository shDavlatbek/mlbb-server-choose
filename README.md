# MLBB Server Lock

Android-приложение для Mobile Legends: Bang Bang. Блокирует **все** игровые серверы, кроме серверов
выбранной страны — и, если нужно, только выбранных городов (например, Россия → только Москва).
Так игра не может отправить вас на матч в Европу или куда-то ещё. Пинг до каждого сервера виден в списке.

Работает как локальный VPN **только для Mobile Legends**: трафик никуда не отправляется, всё
фильтруется прямо на телефоне. Аккаунт, регистрация и интернет-сервис не нужны.

## Почему старое приложение пропускало Европу

Я разобрал APK `MLBB Server Picker` (`com.smetargus.mlbb`). Причины утечки:

1. **Блокировка только по списку портов.** Оно блокирует лишь UDP/TCP `5500–5599` и `30190–30199`,
   а TCP `10000–10100` — только для адресов из своего каталога. Но матч-серверы MLBB работают ещё и на
   UDP `5003`, `5053` и `10000–10099` — эти порты к чужим серверам **не блокировались**.
2. **Всё решает их облачный каталог.** Список «разрешённых» серверов приходит с их сервера
   (`api.smetargus.net`) и требует входа в аккаунт. Пинг (ICMP) блокировался только для серверов,
   которые есть в каталоге. Если европейского сервера нет в каталоге — он считался «не игровым».

## Как работает это приложение

- Весь трафик Mobile Legends (`com.mobile.legends`, `com.mobilelegends.hwag`, `com.mobilelegends.mi`)
  идёт через локальный VPN.
- Для каждого нового соединения определяются **страна и город сервера по IP** — встроенные базы
  DB-IP «IP to Country Lite» и «IP to City Lite» (работают офлайн).
- Если это игровой трафик, а страна (или город) не те, что вы выбрали, — соединение блокируется:
  - UDP пакеты отбрасываются;
  - TCP получает сброс (RST);
  - пинг (ICMP) не проходит — игра видит этот сервер как недоступный.
- Лобби, вход, магазин, загрузки и DNS (TCP/HTTPS, порт 53) **не трогаются**, иначе игра не запустится.

### Режимы

| Режим | Что блокируется к чужим странам |
|---|---|
| **Строгий** (по умолчанию) | весь UDP (кроме DNS/NTP/QUIC), весь пинг, TCP на игровых портах |
| **Мягкий** | только известные порты MLBB: UDP/TCP `5000–5999`, `10000–10199`, UDP `30000–30300`, TCP `30190–30199`, и пинг |

Если в строгом режиме что-то перестало работать (например, голосовой чат) — включите мягкий.

### Выбор города

После выбора страны нажмите «Выбрать город». Вверху списка — города, где уже замечены серверы игры,
с количеством серверов и лучшим пингом; ниже — все города страны из базы (есть поиск).
Ничего не отмечено = открыта вся страна. Маленькие города в базе объединены в регион
(«Namangan (регион)»): серверы игры всё равно стоят в крупных городах.

### Пинг

Приложение само пингует игровые серверы (ICMP, 3 замера, медиана; если телефон не даёт ICMP-сокеты —
через системную утилиту `ping`). Пинг обновляется автоматически, пока открыт главный экран, и по кнопке «Пинг».
Пингуются и заблокированные серверы — так удобно сравнить страны и города. Лучший пинг показан
и в выборе страны, и в выборе города. «Нет ответа» значит, что сервер не отвечает на ICMP (это не значит,
что он не работает).

### Дополнительно

- Список серверов, к которым подключается игра: страна, город, IP, порты, пакеты, пинг, статус (ОТКРЫТ / БЛОК).
- Нажмите на сервер → «всегда разрешать / всегда блокировать этот IP», «разрешить всю страну»,
  «оставить только этот город».
- Ручные правила: IP или подсети (`1.2.3.0/24`) для разрешения/блокировки.
- Можно выбрать несколько стран.
- Если страна не выбрана — режим наблюдения: ничего не блокируется, но видно, куда ходит игра.
- Смена страны применяется сразу: активные соединения к теперь запрещённым серверам обрываются.

## Как пользоваться

1. Установите APK (из раздела Actions/Releases или соберите сами).
2. «Выбрать страну» → например, 🇷🇺 Россия → «Готово».
3. По желанию: «Выбрать город» → например, Moscow → «Готово».
4. «Включить фильтр» → разрешите VPN.
5. Запустите Mobile Legends (если игра уже была открыта — перезапустите её).
6. В списке «Серверы игры» видно, что открыто, а что заблокировано, и пинг до каждого сервера.

> Совет: если сначала не знаете, в какой стране нужные серверы, включите фильтр без страны
> (режим наблюдения), сыграйте матч и посмотрите список — там будут страны серверов.

## Ограничения

- Страна и город определяются по базе IP. Для облачных хостингов они иногда ошибаются.
  Названия городов — на английском, как в базе. Если нужный сервер
  показан не той страной — разрешите его вручную (нажмите на строку → «Всегда разрешать этот IP»).
- Игра сама выбирает сервер матча. Приложение не может «заставить» игру выбрать Ташкент — оно делает
  так, что все остальные серверы недоступны. Если игра всё же подберёт матч на чужом сервере, подключиться
  к нему не получится.
- Одновременно может работать только один VPN на телефоне.

## Сборка

Нужны JDK 17 и Android SDK (platform 35).

```bash
./gradlew testDebugUnitTest   # тесты: пакеты, TCP, UDP, GeoIP, правила
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

GitHub Actions собирает APK на каждый push (артефакт `mlbb-server-lock`), а для тегов `v*` публикует релиз.

Обновить базы стран и городов:

```bash
npm pack @ip-location-db/dbip-country && tar xzf ip-location-db-dbip-country-*.tgz
python3 tools/build_geoip.py package/dbip-country-ipv4-num.csv app/src/main/assets/geoip-v4.bin <yyyymmddhh>

npm pack @ip-location-db/dbip-city-7z && tar xzf ip-location-db-dbip-city-7z-*.tgz
7z x package/dbip-city-ipv4-num.csv.7z
python3 tools/build_geocity.py dbip-city-ipv4-num.csv app/src/main/assets/geocity-v4.bin <yyyymmddhh>
```

## Устройство кода

```
app/src/main/java/io/github/shdavlatbek/mlbblock/
  net/Policy.kt        — что блокировать (страна, режим, порты, ручные правила)
  net/GeoIp.kt         — IP → страна (бинарный поиск по базе DB-IP)
  net/GeoCity.kt       — IP → город (база распаковывается один раз и читается через mmap)
  vpn/Pinger.kt        — пинг серверов
  net/Packets.kt       — разбор и сборка IPv4/UDP/TCP/ICMP пакетов
  vpn/Engine.kt        — пересылка UDP, разбор TCP и ICMP, применение правил
  vpn/TcpFlow.kt       — TCP-соединение: окно, подтверждения, повторная отправка, закрытие
  vpn/IcmpForwarder.kt — пинг до разрешённых серверов
  vpn/LockVpnService.kt— VPN-сервис только для Mobile Legends
  ui/                  — экраны
```
